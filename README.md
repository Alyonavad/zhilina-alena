# Alyona Zhilina — portfolio prototype

A single-page prototype of my product design portfolio ("Chapters" direction): a dark, content-first home page that walks through four case studies one at a time.

- Open `index.html` in any browser — no build step or dependencies.
- Photos live in `images/`.
- Case titles, descriptions, tags and screenshots are placeholders for now.

To publish it as a website, enable **GitHub Pages** (Settings → Pages → deploy from the `main` branch, root folder).
